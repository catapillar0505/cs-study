# 이미지 레지스트리 — Harbor

컨테이너 이미지를 저장하고 배포하는 서버입니다. 도커 허브 같은 걸 회사 안에 직접 두고 쓰는 것이라고 보면 됩니다.

레지스트리가 왜 필요하냐면, 컨테이너를 실행하려면 이미지가 필요한데 그 이미지를 어딘가에서 받아와야 하기 때문입니다. 이미지를 만들어서 레지스트리에 올려두면, 노드들이 필요할 때 받아 갑니다.

Harbor는 CNCF 프로젝트이고 온프레미스에 설치해서 쓰는 오픈소스입니다. 기본 레지스트리에 없는 기능들이 있습니다. 프로젝트 단위 권한 관리, 이미지 취약점 스캔, 이미지 서명, 여러 지역 간 복제 같은 것들입니다.

온프레미스에서 자체 레지스트리를 두는 이유가 몇 가지 있습니다. 외부 인터넷 의존을 줄이고, 이미지를 사내에 보관해 보안 요구사항을 맞추고, 네트워크가 가까워서 pull이 빠릅니다.

주의할 점은 레지스트리의 위치입니다. 레지스트리가 관리망에 있고 워커 노드가 테넌트 네트워크에 있으면, 이미지 pull 트래픽이 중앙 SNAT를 경유하게 되어 배포할 때마다 그 지점이 병목이 됩니다.
