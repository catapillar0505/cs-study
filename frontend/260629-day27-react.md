# JSX Babel 에러 트러블슈팅

## 에러 메시지

Uncaught SyntaxError: importSource cannot be set when runtime is classic.


## 원인

`@babel/standalone`의 최신 버전에서 `data-presets="react"`를 사용하면,
내부적으로 JSX 런타임이 **automatic** 모드로 설정되면서 `importSource: "react"`가 자동으로 지정됩니다.

여기에 `/** @jsxRuntime classic */` pragma 주석을 함께 쓰면,
**classic 런타임**과 `importSource`가 동시에 설정되어 충돌이 발생합니다.

> CDN/UMD 방식 (script 태그로 React를 불러오는 방식)에서는
> `React.createElement`를 직접 사용하는 **classic 런타임**이 적합합니다.
> automatic 런타임은 번들러(Vite, webpack 등) 환경에서 사용합니다.

## 해결 방법

`@babel/standalone`이 로드된 직후, `text/babel` 스크립트들보다 **먼저** 아래 스크립트를 추가합니다.

```html
<script>
  Babel.registerPreset("react-classic", {
    presets: [[Babel.availablePresets["react"], { runtime: "classic" }]],
  });
</script>
그리고 모든 <script type="text/babel"> 태그의 속성을 변경합니다.


<!-- 변경 전 -->
<script type="text/babel" data-presets="react">

<!-- 변경 후 -->
<script type="text/babel" data-presets="react-classic">
요약
항목	내용
문제	data-presets="react" (automatic) + /** @jsxRuntime classic */ 충돌
원인	최신 Babel은 react preset 기본값이 automatic runtime으로 변경됨
해결	Babel.registerPreset으로 classic runtime을 명시한 커스텀 프리셋 등록
적용 범위	CDN/UMD 방식으로 React를 사용하는 모든 HTML 파일
