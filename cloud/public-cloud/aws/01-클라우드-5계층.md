# 클라우드 5계층 — 전체 지도

## 0. 클라우드 5계층 — 전체 지도

> **한 줄 요약**
> 클라우드가 만들어지는 과정을 **아래에서 위로 5단계**로 쪼갠 것. 아래층이 있어야 위층이 존재한다.

### 아파트로 보면

```
5. 서비스 계층      🏠 세입자가 실제로 쓰는 집 + 입주 신청 앱
        ↑
4. 서비스 관리체계   👮 관리사무소 (관리비, 고장 신고, 보안)
        ↑
3. 프로비저닝       🔑 계약하면 열쇠 주고 입주시키기
        ↑
2. 가상화          🧱 칸막이로 세대 나누기
        ↑
1. 물리적 시스템     🏢 건물, 땅, 전기
```

### 한 줄씩

| 계층 | 한 줄 설명 | AWS 예시 |
|---|---|---|
| **1. 물리적 시스템** | 진짜 **쇳덩이**. 서버, 저장장치, 네트워크 장비, 건물 | 데이터센터, 물리 서버 |
| **2. 가상화** | 그 쇳덩이를 **칸막이로 쪼갬** | Nitro 하이퍼바이저 |
| **3. 프로비저닝** | 필요한 만큼 **자동으로 만들어서 건네줌** | 버튼 누르면 EC2 생성, Auto Scaling |
| **4. 서비스 관리체계** | **감시하고 요금 매기고 지켜줌** | CloudWatch, IAM, 요금 청구 |
| **5. 서비스 계층** | 사용자가 **실제로 만나는 화면과 기능** | EC2·S3·RDS 콘솔, API |

### 각 층의 핵심 질문

| 계층 | 질문 |
|---|---|
| 1. 물리 | **뭘로 만드나?** → 쇳덩이 |
| 2. 가상화 | **어떻게 쪼개나?** → 하이퍼바이저 |
| 3. 프로비저닝 | **어떻게 나눠주나?** → 자동 생성 |
| 4. 관리체계 | **어떻게 관리하나?** → 감시·과금·보안 |
| 5. 서비스 | **뭘 쓰나?** → IaaS / PaaS / SaaS |

### 가장 헷갈리는 3번

**프로비저닝 = "준비해서 건네주는 것"** 입니다.

2번(가상화)이 칸막이를 세우는 것이라면, 3번은 **"302호를 김철수 씨에게 배정하고 열쇠를 주는 것"** 이에요.

옛날엔 서버 한 대 받는 데 몇 주가 걸렸지만 지금은 몇 분이면 끝나는데, **그 자동화를 담당하는 층**입니다.

> 💡 이 문서의 Part 2~6은 주로 **5번(서비스 계층)에서 네트워크를 다루는 법**,
> Part 7은 **2번(가상화)의 원리**를 설명합니다.
