# Bastion Host

## 13. Bastion Host

> **한 줄 요약**
> **관리사무소를 거쳐서 안쪽 동에 들어가는 것.**

### 비유

프라이빗 동은 정문에서 바로 못 갑니다. 그래서 이렇게 가요.

```
개발자 → 정문 → 관리사무소(퍼블릭 동) → 프라이빗 동
                    ↑ 배스천
```

### 자주 하는 오해

| 오해 | 사실 |
|---|---|
| 배스천은 프라이빗 서브넷에 둔다 | **퍼블릭에 둡니다.** 자기가 인터넷에 닿아야 하니까 |
| 프라이빗이라서 SSH가 필요하다 | SSH는 원래 쉘 접속 수단. **한 번 더 거칠 뿐** |
| 인바운드는 다 배스천을 거친다 | 배스천은 **관리자 전용**. 사용자는 ALB로 갑니다 |

### 두 갈래 길

```
사용자  → 정문 → ALB       → Spring Boot 서버   (443번)
개발자  → 정문 → 배스천     → 같은 서버          (22번)
```

### 요즘은 안 씁니다

**SSM Session Manager**를 쓰면 배스천이 아예 필요 없어요.
22번 포트를 하나도 안 열고도 접속됩니다. 관리할 서버 한 대와 키 파일이 줄어들어요.
