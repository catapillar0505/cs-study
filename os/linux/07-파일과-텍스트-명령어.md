# 파일 · 텍스트 다루기 명령어

## 파일/디렉토리 조작
```bash
ls -l -a -h          # 목록(상세/숨김/읽기좋은 단위)
cd, pwd              # 이동, 현재 경로
cp -r src/ backup/   # 복사 (-r: 재귀)
mv                   # 이동/이름변경
rm -r -f             # 삭제 (-r: 재귀, -f: 강제)
mkdir -p /a/b/c      # 디렉토리 생성 (-p: 부모 자동 생성, 이미 있어도 에러 X)
find / -name "파일명"  # 파일 찾기
```

- **`-r`(recursive, 재귀)**: 하위 폴더 안의 하위 폴더까지 끝까지 다 처리.
  - `cp`/`rm`은 **대상이 디렉토리이기만 하면** `-r` 필요(중첩 여부 무관).
- **`-p`(mkdir)**: parents. 상위 디렉토리 없으면 자동 생성. (참고: `cp -p`의 `-p`는 preserve로 의미 다름 — 명령어마다 다르니 관용구로 암기)
- **`rm -rf` 주의**: 되돌릴 수 없는 완전 삭제. 휴지통 없음.

## 텍스트 확인
```bash
cat file             # 내용 출력 (concatenate)
cat > memo.txt       # 키보드 입력을 파일로 저장 (Ctrl+D로 종료)
less file            # 한 화면씩 (more의 개선판, "less is more" 말장난)
head / tail          # 앞/뒤 부분
tail -f              # 실시간 추적
grep '패턴' file      # 검색 (Globally search a Regular Expression and Print)
wc -l                # 줄 수 (Word Count, -l=lines)
```

- **cat**은 입력이 파일이면 파일 내용, 없으면 키보드(표준 입력)를 읽음. `cat > 파일`은 키보드→파일 저장 트릭.

## 파이프와 리다이렉션
```bash
ls | grep 'abc'          # 파이프: 앞 명령 출력 → 뒤 명령 입력
ls | grep 'abc' | wc -l  # 여러 개 연결 가능
ls > list.txt            # 표준출력을 파일로 (덮어쓰기)
ls >> list.txt           # 파일에 추가(append)
```
- **표준 출력(stdout)**: 명령어 결과가 기본적으로 나가는 곳(기본은 화면).
- 리눅스 3대 입출력: stdin(키보드), stdout(화면), stderr(화면).
- **파이프(`|`)**: 출력 → 다른 **명령어**의 입력. **리다이렉션(`>`)**: 출력 → **파일**.

## 원격 파일 전송: scp vs rsync
```bash
scp file.txt user@server:/path/     # secure copy — 통째로 복사
rsync -avz file.txt user@server:/path/  # remote sync — 차이(delta)만 전송
```
| | scp | rsync |
|---|---|---|
| 방식 | 통째로 복사 | 차이만 전송 |
| 재실행 | 매번 전체 재전송 | 바뀐 부분만 |
| 용도 | 한 번 빠르게 | 반복 백업/대용량 동기화 |
- rsync 옵션: `-a`(속성 보존), `-v`(상세 출력), `-z`(압축 전송).
