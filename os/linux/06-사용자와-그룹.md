# 사용자와 그룹 관리

## 기본 그룹 vs 보조 그룹
- **기본 그룹(Primary)**: 계정 생성 시 자동 배정되는 딱 하나. 새 파일 생성 시 기본 소유 그룹.
- **보조 그룹(Secondary)**: 기본 외 추가로 속하는 그룹들(여러 개 가능).

## 사용자/그룹 명령어
```bash
sudo useradd -m alice      # 계정 생성 (-m: 홈 디렉토리 생성)
sudo userdel alice         # 계정 삭제
sudo usermod -aG dev alice # 보조 그룹 추가
sudo passwd alice          # 비밀번호 설정
id                         # uid/gid/그룹 확인 (실무 최다 사용)
groups                     # 속한 그룹 목록
cat /etc/group             # 전체 그룹 정의
```

- **`useradd -m`의 `-m`**: make home directory. RHEL 계열은 이 옵션 없으면 홈 디렉토리 안 생김.
- **`useradd` vs `adduser`**:
  - `useradd`: 저수준, 옵션 명시 필요, 모든 배포판 표준.
  - `adduser`: 고수준 스크립트, 대화형으로 알아서 처리(Debian/Ubuntu 계열). RHEL엔 없거나 심볼릭 링크.
  - 자동화/호환성엔 `useradd`, 개인 편의엔 `adduser`.

## usermod -aG (⚠️ 시험 단골 함정)
```bash
sudo usermod -aG dev alice   # ✅ 안전 (기존 그룹 유지 + 추가)
sudo usermod -G dev alice    # ⚠️ 위험 (기존 보조 그룹 다 사라지고 덮어씀)
```
- `-a` = append(추가), `-G` = 보조 그룹.
- **리다이렉션 비유**: `-aG`는 `>>`(추가), `-G`만은 `>`(덮어쓰기).
- `-G`의 글자는 **G**roup에서 왔지만, 대문자 `-G`는 관례적으로 "보조 그룹"을 다룸(소문자 `-g`는 기본 그룹).

## sudo, su, 권한
- **sudo** (superuser do): 이 명령 한 줄만 관리자 권한으로 실행. 끝나면 일반 권한 복귀.
- **su** (switch user): 아예 다른 사용자(보통 root)로 전환, exit 전까지 유지.
- 보안상 계속 root로 있는 `su`보다 필요할 때만 빌리는 `sudo` 권장.
- **sudo 그룹 ≠ root**: sudo를 쓸 "자격"을 가진 그룹. root는 최고 권한 계정 자체(uid=0).
- **GID 숫자(예: 27)는 고정 아님** — 배포판/설치마다 다름. 이름(`sudo`, `wheel`)으로 판단.
  - RHEL 계열은 관리자 그룹으로 `sudo` 대신 `wheel` 사용.
