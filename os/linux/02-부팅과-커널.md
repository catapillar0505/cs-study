# 부팅 과정과 커널

## 부팅 순서
```
1. 전원 켜짐
   ↓
2. BIOS / UEFI (마더보드 내장 펌웨어)
   - 하드웨어(CPU, 메모리) 점검(POST)
   - 부팅할 저장장치 결정 → 부트로더 실행
   ↓
3. 부트로더(GRUB)
   - OS 선택 메뉴 제공
   - 커널 파일을 디스크→메모리로 로드
   - 커널에 실행 권한 넘김
   ↓
4. 리눅스 커널
   - 하드웨어 초기화, 드라이버 로드
   - 최초의 사용자 공간 프로세스(systemd) 생성 + 실행
```

## 약자와 역할
- **BIOS** (Basic Input Output System): 오래된 펌웨어. 하드웨어 점검, 부트로더 실행.
- **UEFI** (Unified Extensible Firmware Interface): BIOS의 후속/개선판. 그래픽 UI, 2TB 이상 디스크 지원, 빠른 부팅, Secure Boot.
- **GRUB** (GRand Unified Bootloader): 부트로더. OS 선택 메뉴, 커널 로드.

## 커널이란?
- **물리적 장치가 아니라 소프트웨어(프로그램)**. 디스크(`/boot/vmlinuz-...`)에 파일로 저장되어 있다가 부팅 시 메모리로 로드되어 실행됨.
- "커널이 올라온다" = 디스크에 있던 커널을 메모리로 끌어올려 실행 시작.
- 역할: CPU 스케줄링, 메모리 관리, 하드웨어 드라이버 처리, 프로세스 간 통신, 파일시스템 관리.

## vmlinuz 이름의 유래
```
vmlinuz = vm(virtual memory, 가상메모리) + linu(Linux) + z(gzip 압축됨)
```
- **vm은 가상머신(Virtual Machine)이 아니라 "가상 메모리"** — 초창기 커널이 가상 메모리를 지원한 것을 강조.
- z는 gzip으로 압축되었다는 표시.
