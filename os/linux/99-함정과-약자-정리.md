# 리눅스 — 헷갈리는 함정과 약자 정리

## 핵심 "데몬 ↔ CLI 도구" 패턴 정리 (반복 등장!)

| 저수준 (실제 작업 수행) | 고수준 (쉬운 인터페이스) |
|---|---|
| `systemd` | `systemctl` |
| `NetworkManager` | `nmcli` |
| `iptables` | `ufw` |
| `dockerd` | `docker` |

- 실제 일을 하는 백그라운드 데몬 + 그걸 편하게 조작하는 CLI 도구로 나뉘는 구조.
- 리눅스 생태계 전반의 흔한 설계 방식. 비슷한 이름 쌍을 만나면 이 구조를 떠올릴 것.

## 시험 대비 — 헷갈리기 쉬운 함정 총정리

| 함정 | 정답 |
|---|---|
| `o`는 owner다? | ❌ **others**(그 외 나머지). owner는 `u`(user) |
| umask 값이 부여되는 권한이다? | ❌ **차단(빼는)** 권한 |
| SetUID를 디렉토리에 걸면 효과 있다? | ❌ 효과 없음 (디렉토리는 **SetGID**만 의미) |
| `usermod -G`만 써도 그룹 잘 추가됨? | ❌ 기존 보조 그룹 다 날아감. **`-aG`** 필수 |
| `kill 1234`는 강제 종료다? | ❌ 기본은 **SIGTERM(15)**, 정중한 요청 |
| `kill -9`는 모든 프로세스를 죽인다? | ❌ **D 상태**는 SIGKILL도 못 죽임 |
| `Ctrl+Z` 하면 백그라운드 실행된다? | ❌ **정지(T)** 상태. `bg` 쳐야 실행 |
| 마운트는 파일을 복사하는 것이다? | ❌ 접근 경로 연결(복사 아님) |
| 데몬은 터미널에 연결된 백그라운드다? | ❌ 데몬은 **터미널 연결 자체 없음** |
| cp로 디렉토리 복사 시 중첩일 때만 -r? | ❌ **디렉토리이기만 하면** 항상 -r |
| systemctl이 systemd를 관리하는 상위다? | ❌ 대등한 "리모컨↔몸통". 실제 관리는 systemd |
| vmlinuz의 vm은 가상머신이다? | ❌ **가상 메모리**(virtual memory) |
| IP(프로토콜)와 IP 주소는 다른 IP다? | ❌ 같은 IP. 규약 자체 vs 그 규약이 부여한 주소값 |
