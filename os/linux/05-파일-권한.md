# 파일 권한(Permission)

## 권한 기본 구조
```bash
ls -l   # -l = long listing format (상세 정보)
# -rwxr-xr--  ...
```
- 맨 앞 1글자: `-`(파일), `d`(디렉토리)
- 나머지 9글자: 3글자씩 소유자/그룹/기타의 rwx

| 대상 | 기호 | 의미 |
|---|---|---|
| 소유자 | **u** | user (그 파일 소유자) |
| 그룹 | **g** | group (소유자의 그룹 구성원) |
| 기타 | **o** | **others** (그 외 나머지 전부) — ⚠️ owner 아님! |

- 권한 종류: **r**(read=4), **w**(write=2), **x**(execute=1)

## chmod (change mode)
```bash
chmod 755 file       # rwxr-xr-x (숫자 방식)
chmod u+x file       # 소유자에 실행권한 추가 (문자 방식)
chmod g-w file       # 그룹에서 쓰기권한 제거
```
- **mode** = 권한 정보를 나타내는 값(예: `755`, `rwxr-xr-x`). `chmod`는 그 값을 바꾸는 것.

**숫자 계산 (r=4, w=2, x=1)**
```
7 = 4+2+1 = rwx
5 = 4+1   = r-x
6 = 4+2   = rw-
```

## 파일 vs 디렉토리 삭제/실행 권한 포인트
- 실행 권한(`x`)은 **프로그램/스크립트**에만 필요. 설정 파일(`.yaml`, `.conf`)에는 불필요.
- 파일 **내용 수정**은 그 파일의 `w` 권한, 파일 **삭제/이름변경**은 그 파일이 든 **디렉토리**의 `w` 권한으로 결정.

## 특수 권한 (4자리)
```bash
chmod 4755 file   # SetUID
chmod 2770 dir    # SetGID
chmod 1777 dir    # Sticky Bit
chmod 3770 dir    # SetGID + Sticky
```

| 값 | 이름 | 파일에 걸면 | 디렉토리에 걸면 |
|---|---|---|---|
| **4000** | SetUID | 실행 시 **소유자 권한**으로 동작 | **효과 없음** |
| **2000** | SetGID | 실행 시 **소유 그룹 권한**으로 동작 | 새 파일이 **디렉토리 그룹** 상속 |
| **1000** | Sticky | (거의 안 씀) | **삭제/이름변경을 파일 소유자만** 가능 |

- **SetUID 원리**: 걸린 실행 파일은 누가 실행하든 소유자 권한으로 동작 (예: `passwd`가 root 소유+SetUID).
  - 보안 위험: `/bin/bash`에 SetUID를 걸면 `bash -p`로 누구나 root 획득(백도어).
  - `bash -p`의 `-p`(privileged): bash가 SetUID 시 스스로 권한을 낮추는 안전장치를 끔.
  - SetUID 파일 점검: `find / -perm -4000 -type f 2>/dev/null`
- **SetGID(디렉토리)**: 공유 폴더에서 새 파일 그룹을 자동 통일. 소유자(user)는 안 바뀌고 **그룹만** 상속.
- **Sticky Bit**: **삭제/이름변경만** 제한, **내용 수정은 제한 안 함**. `/tmp`(`1777`)가 대표 사례.

**공유 폴더 전형 패턴 (`3770`)**
```bash
sudo chmod 3770 /data/shared/
```
- `770`: dev 그룹 전체 rwx, 나머지 접근 불가
- SetGID: 새 파일이 dev 그룹 소유가 되도록 통일
- Sticky: 남의 파일은 삭제 못 하게

**자주 쓰는 권한 조합**
| 조합 | 의미 | 용도 |
|---|---|---|
| `600` | rw------- | SSH 개인키, 민감 설정 파일 |
| `644` | rw-r--r-- | 일반 파일 기본값 |
| `700` | rwx------ | 개인 스크립트/폴더 |
| `755` | rwxr-xr-x | 실행 스크립트/디렉토리 기본값 |
| `1777` | Sticky+rwxrwxrwx | `/tmp` |
| `3770` | SetGID+Sticky | 그룹 공유 디렉토리 |
| `4755` | SetUID+rwxr-xr-x | `passwd` 같은 실행 파일 |

## umask
- 새 파일/디렉토리 생성 시 **차단할(빼는) 권한**을 정하는 값 (부여가 아님!).
```
파일 기본값 666 - umask 022 = 644
디렉토리 기본값 777 - umask 022 = 755
```
```bash
umask        # 현재 값 확인 (예: 0022)
umask 027    # 더 엄격하게 설정
```

## chown (change owner)
```bash
chown root:dev /data/shared/   # 소유자=root, 그룹=dev
chown alice file               # 소유자만 변경
chown :dev file                # 그룹만 변경
```
- `소유자:그룹` 문법. "root에서 dev로 바꾸는 것"이 아니라 "소유자·그룹을 지정 설정"하는 것.
