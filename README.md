# cs-study

java/spring/linux/aws/docker/k8s 학습 기록

## 폴더 구조

```
cs-study/
├── git/        # Git 기초
├── java/       # 자료형, 상속과 다형성, JCF/제네릭, 람다, 입출력, 예외
├── database/   # DB 기초, DDL, DQL
├── spring/     # IoC/DI, AOP, 요청과 응답, RESTful API, MyBatis, 트랜잭션, Spring Security, 토큰
├── jpa/        # JPA 1~3 및 QnA
├── frontend/   # JavaScript, React
├── linux/      # 리눅스
├── cloud/      # 가상화(하이퍼바이저, VM), 클라우드
├── docker/     # 도커
└── etc/        # 퀴즈, 마크다운 문법 등
```

파일명은 `YYMMDD-dayN-주제.md` 형식으로, 학습한 날짜와 일차를 나타냅니다.
