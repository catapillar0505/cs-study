# ipc — 서비스 간 통신 (동기)

서비스를 쪼갠 뒤 **서로를 어떻게 부를 것인가**를 정리합니다.
같은 프로그램 안의 메서드 호출이 **네트워크를 건너는 일**로 바뀌면서 생기는 문제와, 그 두 갈래 해법(REST·gRPC)을 다룹니다.

[msa/05 서비스 간 통신](../05-서비스-간-통신.md)의 동기 호출 쪽을 펼친 하위 폴더입니다.
응답을 기다리지 않는 **비동기·이벤트** 쪽은 [eda](../eda/README.md)에 있습니다.

## 한눈에 보는 두 갈래

```
                 서비스 A 가 서비스 B 를 부른다
                            │
        ┌───────────────────┴───────────────────┐
        ▼                                       ▼
   REST (OpenFeign)                          gRPC
   JSON · HTTP/1.1                     Protobuf · HTTP/2
   계약은 문서에                        계약은 .proto 파일에
   오타는 런타임에 발견                  오타는 컴파일 타임에 발견
   브라우저가 직접 호출 가능             브라우저는 직접 호출 불가
   만들기 쉽고 디버깅 편함               빠르고 엄격함
```

**둘 다 목표는 같습니다** — 원격 호출을 로컬 메서드 호출처럼 보이게 하는 것(**RPC**).

## 읽는 순서

배경지식이 없다면 [01](01-서비스-간-통신이란.md)부터 순서대로.
